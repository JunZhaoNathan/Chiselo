## First Preview Post

```text
I am releasing the first public preview of Chiselo.

Chiselo is a macOS visual editor for existing and AI-generated HTML. Its goal is to replace Dreamweaver's existing-HTML visual editing workflow without reproducing the site manager, FTP client, or traditional IDE. It keeps the original HTML as the source document, lets you adjust visible objects directly, reviews changes, and protects saves. Complex dynamic pages use an explicit trusted compatibility mode.

Commercial use is not allowed under the current license. Personal, educational, research, and evaluation use are welcome.

Stars are appreciated if you want to follow the project.
```
