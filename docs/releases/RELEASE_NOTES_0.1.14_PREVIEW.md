# Chiselo 0.1.14 Preview

Chiselo is a native macOS app for visually refining existing HTML files. This preview focuses on table editing stability in Markdown-exported documents and prevents table text from being clipped after accidental geometry edits.

## Highlights

- Bumped the app version to `0.1.14` and the Sparkle build number to `14`.
- Table-internal objects such as cells, rows, table sections, captions, and descendants inside cells are now geometry-locked.
- Table cells remain selectable for text edits, style edits, and table row/column operations.
- Whole `table` elements remain movable and resizable when the table layout itself needs to move.
- Switching from a normal movable object to a table cell now rebuilds the selection box and clears resize handles, avoiding stale controls that imply the cell can be dragged.
- Added regression coverage for Markdown-style tables with `display:block` and `overflow:auto`, including the `免费 → 引导注册/下载` cell scenario.
- Full release preflight passes after the table-cell geometry lock.

## Package Notes

- Local packaging uses Developer ID signing when the signing identity is available.
- Release packaging should use `CHISELO_NOTARIZE=1 scripts/package-dmg.sh` so the DMG is notarized and stapled before the Sparkle appcast is signed.
- Public release updates require uploading both `Chiselo-0.1.14.dmg` and the generated appcast feed.

## Install

Download `Chiselo-0.1.14.dmg` after the release asset is published.

The appcast generated by local packaging is written to:

`outputs/Chiselo-0.1.14-macOS-arm64-appcast.xml`

and mirrored to:

`outputs/latest/appcast-arm64.xml`
