# Chiselo 0.1.24

This release packages the current public-source licensing policy.

- The source is now available under CC BY-NC 4.0: non-commercial use,
  modification, and sharing with attribution are permitted; commercial use
  requires prior written permission.
- The README, contribution guide, repository topics, product strategy, and
  trademark policy now consistently describe the non-commercial boundary.
- `v0.1.23` and earlier tagged releases retain the Apache-2.0 license supplied
  with those historical versions.

This Apple Silicon macOS package is signed with Developer ID, notarized, and
stapled. Sparkle update metadata is published to the Chiselo R2 feed.
