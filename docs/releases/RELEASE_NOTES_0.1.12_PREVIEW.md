# Chiselo 0.1.12 Preview

Chiselo is a native macOS app for visually refining existing HTML files. It is focused on modifying HTML you already have, not building websites from scratch.

## Highlights

- Added Sparkle update checking for packaged macOS builds through the `检查更新…` menu.
- The DMG packaging script now embeds and signs `Sparkle.framework`, writes `SUPublicEDKey` and `SUFeedURL`, supports Apple notarization/stapling with `CHISELO_NOTARIZE=1`, and generates signed Sparkle appcast files after stapling.
- Bumped the app version to `0.1.12` and the Sparkle build number to `12`.
- Stabilized direct HTML object editing for flow-based diagrams: single-object selection, stable canvas sizing, text-edit cleanup when selecting another object, and transform-based drag/resize for text, pills, cards, and images inside flex/grid/inline layouts.
- Compacts the left object tree for high-fidelity app prototypes so decorative icons and tiny control internals do not make the operable structure list unnecessarily long.
- Added an INKMOSS high-fidelity prototype regression that covers page interactions, drag, resize, style edits, text edits, layout changes, duplicate/delete, undo/redo, and clean HTML export.
- Fixed repeated canvas clicks causing the rendered page to shrink inward.
- Fixed fixed-position overlays and undo/redo snapshot restores causing direct HTML pages to grow, shrink, or recalculate their stage size unexpectedly.
- Fixed selected text state preventing the active object from dragging.
- Fixed stale native text selection making two objects appear selected at the same time.

## Package Notes

- Local packaging uses Developer ID signing when the signing identity is available.
- Release packaging should use `CHISELO_NOTARIZE=1 scripts/package-dmg.sh` so the DMG is notarized and stapled before the Sparkle appcast is signed.
- Public release updates require uploading both `Chiselo-0.1.12.dmg` and the generated appcast feed.

## Install

Download `Chiselo-0.1.12.dmg` after the release asset is published.

The appcast generated by local packaging is written to:

`outputs/Chiselo-0.1.12-macOS-arm64-appcast.xml`

and mirrored to:

`outputs/latest/appcast-arm64.xml`
