# Chiselo 0.1.13 Preview

Chiselo is a native macOS app for visually refining existing HTML files. This preview focuses on release consistency and making the editing surface feel stable on dense high-fidelity prototypes.

## Highlights

- Bumped the app version to `0.1.13` and the Sparkle build number to `13`.
- Packaged builds now show a version/build fingerprint in the toolbar. Dirty working-tree changes are included in the fingerprint so two builds with the same version can still be distinguished.
- Rebalanced the macOS layout around the canvas: the center editor gets more default width, while the navigator and inspector take less pressure.
- Renamed the HTML page overlay to `内容边界` so the visible guide reads as the stable content area, not as the page itself shrinking.
- Reworked the inspector into `内容 / 外观 / 位置 / 层级 / 源码`, with text, image, table, and quick adjustment controls surfaced before DOM/source details.
- Added direct text editing for the currently selected object from the inspector content tab.
- Kept direct HTML editing single-selection first: one selected object, one changed object, no unrelated layout movement.
- Reduced accessibility and object-tree noise by hiding visual overlay layers from assistive technologies and adding clearer object-tree labels.
- Continued INKMOSS prototype regression coverage for selection, drag, resize, text edits, style edits, layout changes, duplicate/delete, undo/redo, and clean export.

## Package Notes

- Local packaging uses Developer ID signing when the signing identity is available.
- Release packaging should use `CHISELO_NOTARIZE=1 scripts/package-dmg.sh` so the DMG is notarized and stapled before the Sparkle appcast is signed.
- Public release updates require uploading both `Chiselo-0.1.13.dmg` and the generated appcast feed.

## Install

Download `Chiselo-0.1.13.dmg` after the release asset is published.

The appcast generated by local packaging is written to:

`outputs/Chiselo-0.1.13-macOS-arm64-appcast.xml`

and mirrored to:

`outputs/latest/appcast-arm64.xml`
